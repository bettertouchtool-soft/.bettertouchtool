## 🧠 Core Capabilities


A deeper look at the features that define BetterTouchTool.


### 🪄 Gesture Triggers


BetterTouchTool can recognize hundreds of distinct gestures. For trackpads, this includes taps, clicks, swipes, pinches, rotations, and force touches. For mice, it supports button combinations, scroll directions, and tilt. Keyboard shortcuts, function keys, and even AppleScript events can also serve as triggers. The system is designed to be responsive—gestures are detected with low latency, making them feel natural.


### 🧩 Action Chains


Single gestures can trigger multiple actions in sequence. For example, you can assign a three‑finger swipe to: minimize the current window, open a specific app, and play a sound—all at once. The action library includes system commands (volume, brightness, media control), keyboard shortcuts, clipboard operations, window management, and script execution.


### 🪞 Context‑Aware Profiles


Every gesture can be bound to a specific application, window title, or even screen resolution. This means a three‑finger tap can mean "open Safari" when you're on the desktop, "paste plain text" in a document, and "mute microphone" in a video call—all automatically.


### 🔄 Automation Integration


BetterTouchTool integrates with macOS automation technologies. You can run AppleScript, Shell scripts, and Automator workflows directly from gestures. It also works with third‑party tools like Keyboard Maestro and Alfred, making it a great addition to existing automation setups.


### 🪟 Window Management


The built‑in window snapping system allows you to position windows with gestures. Drag a window to a corner, use a keyboard shortcut, or trigger a gesture—BetterTouchTool will resize and position it according to your predefined layout. It supports multi‑monitor setups and remembers window positions per application.


### 🎛️ Touch Bar Customization


For MacBook Pro users, BetterTouchTool unlocks the full potential of the Touch Bar. You can create custom control strips for any application, add sliders, buttons, and even widget‑style controls. The Touch Bar becomes a context‑sensitive dashboard that changes as you switch between apps.

## 🛠️ Setup & Getting Started


BetterTouchTool is designed to be intuitive from the moment you install it. Here's how to start your customization journey.


### Step 1 — Download & Install


Download BetterTouchTool and move it to your Applications folder. The first launch will ask for accessibility permissions—this is required for gesture interception.


### Step 2 — Grant Accessibility Permission


BetterTouchTool needs access to control your Mac. Go to **System Settings → Privacy & Security → Accessibility** and enable BetterTouchTool. Without this, gestures cannot be recognized.


### Step 3 — Open the Preferences Window


The main interface is clean and well‑organized. On the left, you'll see your list of profiles—Global is selected by default. On the right, you can add new gestures, define triggers, and assign actions.


### Step 4 — Assign Your First Gesture


Click the **+** button, perform a gesture on your trackpad or mouse, and then assign an action from the dropdown. For example, assign a three‑finger tap to **Launch Application → Safari**. Test it immediately—BetterTouchTool responds in real time.


### Step 5 — Add Application‑Specific Profiles


Click the **+** under "Application Specific" and select an app. Now any gesture you add to this profile will only apply when that app is active. This is where the real power of BetterTouchTool emerges.

## 🧯 Troubleshooting Guide


Common issues and how to resolve them.


### Gestures Not Recognized


**Problem:** BetterTouchTool does not respond to certain gestures.


**Solution:** Verify that accessibility permissions are granted in System Settings. Also, ensure that the gesture isn't already assigned to a conflicting action in another profile. Restarting BetterTouchTool or your Mac can sometimes resolve detection issues.


### Application‑Specific Profile Not Activating


**Problem:** Gestures configured for a specific app do not trigger when that app is active.


**Solution:** Confirm that the application is correctly selected in the profile settings. If the app has multiple windows with different titles, consider using window‑specific rules. Also, check that the profile is enabled.


### High CPU Usage


**Problem:** BetterTouchTool uses significant CPU resources.


**Solution:** Reduce the number of active gestures or simplify complex action chains. Disable unused input sources (e.g., MIDI if not in use). Updating to the latest version often includes performance improvements.


### Touch Bar Not Showing Custom Layout


**Problem:** Touch Bar remains unchanged after customizing.


**Solution:** Ensure that BetterTouchTool is allowed to control the Touch Bar (System Settings → Privacy). Restart the Touch Bar via Activity Monitor or reboot your Mac. Check that the Touch Bar profile is assigned to the correct app.


### Imported Profile Doesn't Work


**Problem:** A profile imported from another user behaves differently.


**Solution:** Some gestures depend on specific applications or window titles. Adjust the profile to match your installed apps and screen setup.


### BetterTouchTool Crashes on Launch


**Problem:** Application crashes immediately after opening.


**Solution:** Try resetting preferences by moving the configuration file (`~/Library/Preferences/com.hegenberg.BetterTouchTool.plist`) to a backup location. Reinstall the application from a fresh download.
